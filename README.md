# Trader Behavior vs Market Sentiment

## Objective
Analyze how Bitcoin market sentiment (Fear vs Greed) impacts trader performance using historical trade data.

## Datasets Used
- Historical Trader Data (Hyperliquid)
- Bitcoin Fear & Greed Index

## Methodology
- Data cleaning and preprocessing
- Merging trades with daily market sentiment
- Performance analysis using closed PnL
- Visualization of sentiment-based performance patterns

## Key Insights
- Trader performance varies significantly across Fear and Greed periods
- Greed phases show higher average PnL and leverage usage
- Fear phases indicate more conservative trading behavior

## Tools Used
- Python
- Pandas
- Matplotlib
